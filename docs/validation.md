## Что остаётся

Подключение ChatGPT Web через приватный Secure MCP Tunnel требует выбора транспорта, прав аккаунта и runtime-ключа; ничего не опубликовано. Desktop-подключение не проверено. Полный каталог, остатки конкретного магазина и все мелкие условия акций недоступны из одного JSON. Автоматическое OCR, OAuth-шлюз публичного HTTPS, смешанные SKU-акции и разделение одной строки между разными товарами не реализованы; такие условия нельзя молча считать поддержанными.

Для повторения HTTP-демонстрации с этими свежими проверенными примерами запустите сервер в одном терминале, затем `uv run python scripts/demo-mcp.py` в другом. Скрипт вызывает все четыре MCP-инструмента и сохраняет датированный JSON; после истечения акции проверка условной суммы должна завершиться ошибкой, а не подменять даты.
