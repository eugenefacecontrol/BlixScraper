# Исследование, 05.10.2026

Изучен [jjwallace/polski-price](https://github.com/jjwallace/polski-price): Bun ≥1.3, TypeScript, CSV-хранилище, сбор публичного window.offers и Gemini для аналитики средних цен. package.json содержит только @types/bun как devDependency; Gemini интеграция требует внешнего ключа. В просмотренном checkout не найден файл LICENSE, поле license в package.json отсутствует. Код не копировался: BlixScraper — собственная реализация на Python. polski-price не является готовым MCP и не решает точный расчёт корзины с подтверждёнными условиями.

[robots.txt](https://blix.pl/robots.txt) в реальном ответе:

```
Sitemap: https://blix.pl/sitemaps/sitemap.xml
User-agent: *
Disallow: /lista-zakupow/
Disallow: /shoppinglist/*
Disallow: /api/*
```

[Поиск maslo](https://blix.pl/szukaj/?szukaj=maslo) содержал 14 элементов window.offers. Старый счётчик 97 на текущей странице надёжно не подтверждён; нельзя переносить его из предыдущего исследования. Выдача включала непищевое масло, поэтому совпадение слова не доказывает нужный товар. Поисковая страница не используется как полный каталог.

Страницы сетей имели лишь 6 / 0 / 3 / 2 встроенных предложения (Biedronka / Lidl / Aldi / Kaufland). Газетки возвращают значительно больше JSON-элементов. Наблюдались name, price, brandName, dateStart/dateEnd с Europe/Warsaw, leafletId, pageNumber, image, area и UUID вхождения. Есть null-цены. Цена 249 сопоставлена с 2,49 zł на реальном предложении; для расчёта используется целое число грошей, а не float.

В ходе первого исследования запрос с обычным Python User-Agent к газётке получил 403: повторов для обхода не делалось. Отдельный запуск реализованного коллектора со стабильным идентифицирующим User-Agent получил публичные страницы 31 действующей газетки. Смена IP, прокси, cookies, скрытые API и обходы блокировок не применялись. Коллектор останавливает запросы к сети при 401/403/429.

В реальном JSON `pageNumber` начинается с нуля, в UI и `?pageNumber=` — с единицы. Проверено на молоке Łaciate: JSON 19 → страница 20. Ссылки адаптера учитывают это различие. Полное изображение страницы извлекается из `.page-wrapper` публичного HTML.

Ключевое расхождение: Banany luzem, 299 грошей, Kaufland, 01–07.10.2026. JSON не сообщает обязательную Kaufland Card XTRA, лимит 2 кг и применение цены только к первому чеку за день. На изображении указано 2,99 zł/kg при этих условиях и 6,99 zł/kg без карты/сверх лимита. Поэтому даже непустая JSON-цена не является достаточным доказательством доступной цены. В коде более сложная схема «обычная цена после лимита» не моделируется: сверх подтверждённого лимита предложение исключается.

Публичный HTML и полностью обработанные видимые ссылки не доказывают полноту каталога. Поле `catalog_complete=false` сохраняется; никакие утверждения полски-price о «полном массиве» автоматически не приняты.
